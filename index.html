Configura el token para empezar
Cómo configurar — 3 pasos
1
Crea una cuenta en GitHub (si no tienes)
Ve a github.com y regístrate gratis. No necesitas saber programar.
2
Genera un token de acceso personal
Ve a github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token.
Ponle nombre: FinanzasPro. En permisos marca solo gist. Copia el token (empieza con ghp_) y pégalo arriba. Solo se muestra una vez.
3
Haz clic en "Conectar / Crear Gist"
La app creará automáticamente un Gist privado con tus datos. En otros dispositivos pega el mismo token y el Gist ID que aparecerá aquí, y tus datos estarán disponibles al instante.
